# Security policy

Only the latest release is supported for security fixes. Reports may concern the desktop app, its core and local servers, or the `corrallm` command.

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/jrbarkin/corrallm/security/advisories/new): open this repository's **Security** tab and choose **Report a vulnerability**. Include the affected version (or commit for a source build), operating system, steps to reproduce and impact. Remove credentials and personal data from logs and examples before sharing them.

Never report a vulnerability in a public issue, discussion or pull request.
